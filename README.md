# Leaf 🌿 — Downloads

[Leaf](https://github.com/SaranSundar/leaf-releases/releases/latest) is a calm,
cross-platform space for reading and writing Markdown.

This repository hosts the public builds. The app checks here for new versions
and updates itself — grab an installer once and you're set.

## Installing

- **macOS** — unzip and drop `Leaf.app` into `/Applications`. The app is not
  notarized; on first launch, right-click → Open.
- **Windows** — unzip anywhere and run `leaf.exe`.
- **Linux** — extract and run `./leaf` from the extracted folder.
- **Android** — open the APK and allow installing from this source.

## Updates

Leaf checks this repository for a newer build (at most every 6 hours) and
offers it in-app: Android installs in place; desktop downloads the archive to
your Downloads folder.
